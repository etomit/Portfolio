# LinkedIn : poste chez Daimler Buses GmbH, description proposée

Intitulé, entreprise, lieu et dates inchangés. Tiré du relevé de mes tâches ; le nom du dépôt interne et les numéros de tickets ne sont pas cités.

---

Je développe le nouvel intranet industriel de Daimler Buses France, qui remplace l'ancien : une application React modulaire, avec un socle commun et une dizaine de modules métier branchés sur une API Symfony. Plus de 1 200 salariés s'en servent. Depuis septembre 2024 : environ 640 commits sur 10 dépôts.

- Module PAC (propositions d'amélioration continue), conçu de zéro : dépôt des idées, validation par les managers, notation par un jury, archives et administration.
- Module des demandes internes, dont je suis le principal développeur : outillage, magasin, travaux, stockage, déplacements de véhicules et métrologie, avec un circuit de validation selon les rôles et des tableaux de bord statistiques.
- Socle commun : menus et droits configurables, notes de version des modules, thème clair et sombre pour toute la plateforme, démarrage du serveur de développement passé d'environ 4 minutes à environ 1 seconde.
- Portage des plans de chaîne de production depuis l'ancien intranet : plans interactifs, éditeur d'horaires, export PDF.
- Audits qualité 5S et QGate, avec leurs plans d'action.
- Migration de toute la plateforme vers Vite et MUI 9, et campagne ESLint sur les 10 dépôts : environ 160 erreurs corrigées, une PR par dépôt.

Côté projet, j'organise les réunions avec les services clients, je définis les projets et je les priorise. Avec l'équipe backend, je diagnostique les erreurs d'API et je transmets la liste des corrections à faire.

Outils : React 19, MUI 9, Vite, i18next, Chart.js, Vitest, API REST Symfony (OpenAPI), Mercure, GitHub Enterprise.
